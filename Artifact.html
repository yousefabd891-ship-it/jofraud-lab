Real-time fraud detection dashboard simulating Jordanian banking transactions (CliQ, Visa, IBAN) with AI-powered AML analysis.

📸 Dashboard Preview

Premium dark-mode fintech design inspired by Revolut & Stripe - Built for Jordanian banks

🚀 Key Features

  • 📊 50 Simulated Transactions - Jordan-focused with CliQ, Card, IBAN channels
  • 🚨 Fraud Detection Engine - Risk scoring based on foreign country + odd hour + large amount
  • 💰 Business Impact: Detected 6 fraud cases (12% rate) - Saved 49,836 JOD
  • 🔍 Detailed Investigation Modal - Shows Customer ID, Device, IP, Location Mismatch (e.g., Lagos vs Amman)
  • 🇯🇴 CBJ Compliance - Auto-flags transactions >10,000 JOD for Central Bank of Jordan reporting
  • 🤖 AI Risk Analysis - Bilingual AML alerts (Arabic & English) via Gemini API
  • 📤 Dynamic Data - Upload new CSV (amount,country,channel) and recalculates KPIs instantly

🧠 How Risk Scoring Works

Risk = 0if country != "Jordan" => +40if hour < 6 AM => +30if amount > 5000 JOD => +20if channel == "Visa" => +10if risk >= 75 => Fraud

🛠️ Tech Stack

  • Frontend: React + Tailwind CSS + Recharts
  • AI: Google Gemini 1.5 Flash API
  • Build: Vibe Coded with Claude Artifact (100% mobile-built)
  • Design: Glassmorphism, Dark Mode, Neon Accents
